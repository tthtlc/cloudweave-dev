Part 2 · Cross-cutting questions

An edge is undocumented until all 14 are answered — ask these about every exchange.

  1. Which credential authenticates the caller, and which principal does it name? (provisioner authenticates to OpenFGA; the end user is the subject evaluated — fga.py:276-280)
  2. Synchronous request/response, redirect, callback, or poll? (OIDC 302 in idp_login.py:132; Nutanix task polling)
  3. Exact method + path + Content-Type + body schema? (/check vs /read vs /write; Vault sys/policies vs auth/approle vs secret/data)
  4. Which headers carry state? (Authorization, Cookie, X-Provider-Connection, X-Vault-Token, X-Request-ID, Accept)
  5. Fail-closed or fail-open? (unreachable → 503 at fga.py:234-237 vs enabled=False → True at fga.py:274)
  6. Error status + body shape, and does the other side map it or swallow it? (502 wrap at libcloud_proxy.py:343; _upstream_reason)
  7. Timeouts, retries, cache TTLs per hop? (30 s httpx; 30 s Vault secret + auth-material; token refresh margin)
  8. Idempotent / replay-safe? (OpenFGA tuple dedupe vs non-idempotent AppRole secret-id minting)
  9. Correlation ID through the chain? (X-Request-ID at libcloud.rest — propagated into the subprocess?)
  10. What secret crosses this wire, and is it logged / cachable / in /proc? (provisioner password → shell env, libcloud_proxy.py:880-901)
  11. TLS or plaintext? Loopback / bridge / public interface?
  12. Who can even reach it? (127.0.0.1 vs 0.0.0.0 — portal :3000, visualizer :5050, emulators :9440 are public)
  13. Ordering / startup dependency — is there a race? (no depends_on for OpenFGA; discovery-latch bug, fga.py:135-141)

def _bearer_token_from_request(request):
    header = request.headers.get("Authorization") or request.headers.get("authorization")
    if not header: raise APIError("auth_invalid_token", "Bearer token required", 401)
    parts = header.split(" ", 1)

2 · provisioner access token (Dex JWT, aud=libcloud-rest)

Restricts: identity-service → OpenFGA and identity-service → libcloud.rest (forwarded again libcloud.rest → OpenFGA). Obtained by a server-side LDAP login as aws-admin/ntnx-admin.
source · identity_service/app/idp_login.py:37-45 + 138-148
def _parse_token(tok):
    access = tok.get("access_token", "")
    exp = int(time.time()) + 3600
    payload = jwt.decode(access, options={"verify_signature": False})   # read exp only
    exp = int(payload.get("exp", exp))
    return {"access_token": access, "refresh_token": tok.get("refresh_token", ""), "exp": exp}

tr = client.post(f"{dex}/dex/token", data={
    "grant_type": "authorization_code", "code": code, "redirect_uri": redirect_uri,
    "client_id": s.libcloud_oidc_client_id, "client_secret": s.libcloud_oidc_client_secret,
})
return _parse_token(tr.json())
