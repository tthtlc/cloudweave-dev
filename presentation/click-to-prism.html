A note on “single-use”

Only the login artifacts in §2 are genuinely one-time. Everything after login is a bearer value replayed verbatim until it expires — there is no nonce, request signing, or token denylist on the API path.

Single-use

  • OAuth state & PKCE code_verifier — popped once
  • OAuth authorization code — consumed at Dex
  • OIDC nonce — popped once
  • pending-identity jti — denylisted on use

Replayable until expiry

  • Portal session cookie — 8 h, no jti check
  • libcloud.rest bearer JWT — ~15 min–24 h
  • Prism session cookie — cached 1 h
  • Vault token — 32 days
