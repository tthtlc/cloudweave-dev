# How to Rotate a Dex Preshared Key / OAuth Client Secret

This guide covers **rotation** of the OAuth2 client secret that Dex issues
for the `libcloud-rest` client — the "preshared key" between Dex and its
relying parties (libcloud REST API, OpenFGA's `aud` check, host scripts).

> **What is being rotated.** The `secret` field of the `libcloud-rest`
> `staticClients` entry in `../dex/config.yaml`. It is generated by
> `dex_bootstrap.py` (`secrets.token_urlsafe(32)`) unless
> `LIBCLOUD_OIDC_CLIENT_SECRET` is provided, and written to
> `generated/dex.env` as `LIBCLOUD_OIDC_CLIENT_SECRET`. It is **not** a
> per-user password (those live in LLDAP).

---

## 0. Who consumes the secret

| Consumer | Where it reads the secret | Effect of rotation |
|----------|---------------------------|--------------------|
| libcloud REST API | `../libcloud.rest/.env` (synced from `generated/dex.env`) | must be re-synced + REST API recreated |
| OpenFGA | uses `aud=libcloud-rest`, **not** the secret | **no change** — OpenFGA validates the JWT signature, not the client secret |
| Host scripts (`idp_login.py`, `superadmin_auth.sh`) | `generated/dex.env` | reads new value on next run (no restart) |
| Dex itself | `config.yaml` `staticClients[].secret` | recreated to load new value |

So rotation touches Dex + libcloud REST + host scripts; OpenFGA is unaffected.

---

## 1. Prerequisites

- `setup.sh` has run; Dex and libcloud REST are up.
- You can run `dex_bootstrap.py` (it writes `generated/dex.env` and
  `config.yaml`).
- Brief window where in-flight browser flows are lost
  (`storage.type: memory`).

---

## 2. Rotate

### Option A — use the dedicated rotator

```bash
cd ../openfga_my
SUPERADMIN_JWT=<...> scripts/openfga-presharedkey-rotate.sh
```

`openfga-presharedkey-rotate.sh` re-runs `dex_bootstrap.py` (generating a new
random secret) and recreates the `dex` container.

### Option B — manual, picking the secret value

```bash
# 1. Generate (or supply) a new secret:
NEW_SECRET="$(python3 -c 'import secrets; print(secrets.token_urlsafe(32))')"

# 2. Re-render Dex config with the new secret:
cd ../openfga_my
LIBCLOUD_OIDC_CLIENT_SECRET="$NEW_SECRET" SUPERADMIN_JWT=<...> \
  python3 dex_bootstrap.py

# 3. Recreate Dex to load the new config.yaml:
docker compose -f ../dex/docker-compose.yml up -d --force-recreate dex

# 4. Wait for discovery to come back:
until curl -fsS http://localhost:5556/dex/.well-known/openid-configuration >/dev/null; do
  sleep 1
done

# 5. Sync the new secret into the libcloud REST API:
#    (setup.sh does this automatically; manually:)
grep '^LIBCLOUD_OIDC_CLIENT_SECRET=' generated/dex.env >> ../libcloud.rest/.env.new
# or re-run the relevant env-sync block of setup.sh, then:
docker compose -f ../libcloud.rest/docker-compose.yml up -d --force-recreate libcloud-rest
```

---

## 3. Post-rotation checks

```bash
# Dex is healthy:
curl -fsS http://localhost:5556/dex/.well-known/openid-configuration | jq .issuer

# A fresh login still works and the new token validates at OpenFGA:
LIBCLOUD_USER=aws-admin LIBCLOUD_PASSWORD='<pw>' scripts/idp_login.py >/tmp/jwt
scripts/openfga-check.sh user:aws-admin can_connect libcloud_api:main

# libcloud REST accepts the new token:
curl -s -H "Authorization: Bearer $(cat /tmp/jwt)" http://localhost:8765/v1/auth/me
```

Old refresh tokens are invalid after the recreate (in-memory storage); users
must re-login.

---

## 4. Files touched

| File / store | What changes |
|--------------|--------------|
| `../dex/config.yaml` | `staticClients[0].secret` re-rendered (do not hand-edit) |
| `generated/dex.env` | `LIBCLOUD_OIDC_CLIENT_SECRET` overwritten |
| `../libcloud.rest/.env` | `LIBCLOUD_OIDC_CLIENT_SECRET` re-synced |
| `generated/dex_audit.log` (if present) | rotation audit line |
| OpenFGA | **unchanged** |

---

## 5. Quick reference

| Action | Command |
|--------|---------|
| Rotate (helper) | `SUPERADMIN_JWT=… scripts/openfga-presharedkey-rotate.sh` |
| Rotate (manual) | `LIBCLOUD_OIDC_CLIENT_SECRET=… python3 dex_bootstrap.py` then recreate `dex` |
| Recreate Dex | `docker compose -f ../dex/docker-compose.yml up -d --force-recreate dex` |
| Recreate REST API | `docker compose -f ../libcloud.rest/docker-compose.yml up -d --force-recreate libcloud-rest` |
